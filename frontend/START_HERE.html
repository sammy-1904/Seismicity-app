⚠️

HTTP Server Required!

This application cannot run directly from the file system.

You need to start a local HTTP server to avoid CORS errors when loading CSV data.

❌ Don't: Open index.html by double-clicking it
✅ Do: Use an HTTP server as shown below

🍎 macOS/Linux Users:

  1. Open Terminal
  2. Navigate to this folder
  3. Run: ./start-server.sh
  4. Or: python3 -m http.server 8000
  5. Open browser to: http://localhost:8000

🪟 Windows Users:

  1. Double-click start-server.bat
  2. Or open Command Prompt/PowerShell
  3. Run: python -m http.server 8000
  4. Open browser to: http://localhost:8000

📚 More Options:

  • • PHP: php -S localhost:8000
  • • Node.js: npx http-server -p 8000
  • • VS Code: Install "Live Server" extension

📖 See README.md or README_MACOS.md for detailed instructions
