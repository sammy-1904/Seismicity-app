Aim

Objectives of the Virtual Seismology Lab

This virtual laboratory is designed to provide hands-on experience in analyzing global seismicity patterns using real earthquake data from the ISC-GEM Global Earthquake Catalogue.

Learning Objectives:

  • Understand Earthquake Distribution: Visualize the spatial and temporal patterns of global seismicity
  • Apply the Gutenberg-Richter Law: Learn about the frequency-magnitude relationship of earthquakes
  • Analyze Depth Distributions: Study how earthquakes are distributed at different depths
  • Temporal Analysis: Identify trends and patterns in earthquake occurrence over time
  • Data-Driven Learning: Develop skills in querying, filtering, and analyzing seismic datasets
Dataset: ISC-GEM Global Earthquake Catalogue (1904-2021) containing high-quality earthquake data with moment magnitudes ≥ 5.5

Theory

Seismicity Analysis: Theoretical Background

1. The Gutenberg-Richter Law

The Gutenberg-Richter relationship is a fundamental law in seismology that describes the frequency-magnitude distribution of earthquakes:

log₁₀(N) = a - bM

Where:

  • N = Cumulative number of earthquakes with magnitude ≥ M
  • M = Magnitude
  • a = Activity parameter (total seismicity)
  • b = Slope parameter (typically ~1.0, indicates relative frequency of small vs large events)

2. Earthquake Depth Distribution

Earthquakes occur at various depths, which provide insights into tectonic processes:

  • Shallow (0-70 km): Most common, occur in the crust
  • Intermediate (70-300 km): Occur in subduction zones
  • Deep (300-700 km): Rare, deep subduction zone events

3. Spatial Distribution

Earthquakes are not randomly distributed globally. They primarily occur along:

  • Plate boundaries (convergent, divergent, transform)
  • Subduction zones
  • Mid-ocean ridges
  • Continental rift zones

4. Temporal Patterns

Analyzing earthquake occurrence over time helps identify:

  • Seismic cycles and recurrence intervals
  • Potential changes in seismicity rates
  • Aftershock sequences
  • Long-term trends in seismic activity

Procedure

Step-by-Step Guide to Using the Seismicity Analysis Tool

Step 1: Set Geographic Parameters

  • Navigate to the Simulation tab
  • Use the interactive map to select your region of interest
  • Click on the map or drag the marker to set the center point
  • Adjust the search radius (in kilometers)

Step 2: Set Magnitude and Time Filters

  • Set the minimum magnitude threshold
  • Select the start date (default: 1904-01-01)
  • Select the end date (default: 2021-12-31)
  • Note: ISC-GEM catalogue covers 1904-2021

Step 3: Execute Search

  • Click the Search Earthquakes button
  • The system will filter the catalogue based on your criteria
  • Results will be displayed on the map and in various visualizations

Step 4: Analyze Results

  • Map View: See spatial distribution of earthquakes
  • G-R Plot: Analyze frequency-magnitude relationship
  • Depth Distribution: View depth histogram
  • Temporal Analysis: Study time-series patterns
  • Magnitude Distribution: Examine magnitude histogram

Step 5: Interpret and Export

  • Examine the b-value from the Gutenberg-Richter plot
  • Identify depth patterns (shallow vs deep seismicity)
  • Look for temporal clusters or trends
  • Switch between different map types for better visualization
