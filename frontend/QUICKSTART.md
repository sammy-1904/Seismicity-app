# 🚀 Quick Start - Seismicity App (Standalone Version)

## ✅ You Can Now Open This Directly!

No web server needed! This app now runs as a standalone HTML file.

---

## 📋 Simple 2-Step Setup

### Step 1: Convert Data (One Time Only)

**Windows:**
- Double-click `convert-data.bat`

**macOS/Linux:**
```bash
chmod +x convert-data.sh
./convert-data.sh
```

**Or use Python directly:**
```bash
python convert-csv-to-js.py
```

### Step 2: Open the App

**Windows:**
- Double-click `index.html`

**macOS:**
- Right-click `index.html` → Open With → Safari/Chrome/Firefox

**Linux:**
```bash
xdg-open index.html
```

---

## 📂 What You Need

All these files should be in the same folder:

✅ `index.html` - The main app  
✅ `earthquake-data.js` - Data file (created in Step 1)  
✅ `app.js`, `utils.js`, `components.js`, `navigation.js` - Code  
✅ `styles.css` - Styles  

---

## 🎯 That's It!

The app will open in your browser with:
- 74,000+ earthquake records (1904-2021)
- Interactive map
- Data analysis tools
- Charts and visualizations

---

## ⚡ Troubleshooting

**Problem:** "Earthquake data not loaded" error

**Solution:** Run Step 1 again to create `earthquake-data.js`

---

**Problem:** Blank page

**Solutions:**
1. Check browser console (press F12)
2. Make sure all files are in the same folder
3. Try a different browser
